## Возможности

ArtLab начинался как учебный проект. В нём можно экспериментировать с цветом,
шумом и контурами, а затем отменять изменения и сравнивать результат с оригиналом.
Фильтры работают в браузере; фото не отправляется на сервер для обработки.

| | Что доступно |
| :--- | :--- |
| **Загрузка** | Файл, ссылка, перетаскивание и вставка из буфера. Поддерживается HEIC/HEIF. |
| **Цвет** | Оттенки серого, яркость, негатив, бинаризация, контраст, гамма, квантование, псевдоцвет и соляризация. |
| **Шум и контуры** | Размытие, повышение резкости, медианный фильтр, Собель, Превитт, Кирш, тиснение и другие операции. |
| **Геометрия** | Поворот, отражение по X/Y, изменение размера и обрезка с выбором пропорций. |
| **Просмотр** | Масштаб, перемещение, полноэкранный режим и просмотр оригинала. На телефоне — управление касаниями. |
| **Пипетка** | Цвет пикселя в HEX и RGB, прозрачность и копирование HEX. |
| **История** | Отмена, повтор, сброс и переход к любому сохранённому шагу. Названия операций и миниатюры. |
| **Данные фото** | Интерактивная RGB-гистограмма, формат, разрешение, вес файла и доступные исходные метаданные. |
| **Экспорт** | WebP, PNG и JPEG. Имя, качество и вес готового файла перед скачиванием. |

Интерфейс выполнен в стиле комикса: квадратные элементы, чёткие границы и
смещённые тени. Есть светлая и тёмная темы, русский и английский языки,
выбор акцента. Тема, язык, акцент и вид меню — сетка или список — запоминаются.

На телефоне фотография расположена сверху, а функции, параметры и данные
переключаются вкладками. При обработке поверх фото появляется лёгкий блюр
со спиннером; управление блокируется до завершения операции.

## Запуск

Нужны **Node.js 24+** и **pnpm 12.9.1**.

```sh
git clone https://github.com/RezyJS/rezyjs_artlab.git
cd rezyjs_artlab
pnpm install --frozen-lockfile
pnpm dev
```

Откройте [localhost:3000](http://localhost:3000). Переменные окружения
и отдельный сервер обработки не нужны.

| Команда | Назначение |
| :--- | :--- |
| `pnpm dev` | Разработка |
| `pnpm build` | Production-сборка |
| `pnpm start` | Запуск готовой сборки |
| `pnpm lint` | ESLint и проверка границ FSD |
| `pnpm typecheck` | Проверка типов |

## Визуальный стенд

Рабочий редактор находится на **`/`**. Компоненты и варианты компоновки
можно посмотреть отдельно:

| Страница | Содержимое |
| :--- | :--- |
| `/ui-kit` | Компоненты на основе shadcn/ui, состояния, диалоги и уведомления Sonner |
| `/example` | Демонстрационный интерфейс с каталогом функций и настройками |
| `/mobile` | Пример в рамке телефона: 360, 390 или 430 px |

Обработка и история на стенде демонстрационные. Для работы с фотографией
используйте основной редактор.

## Горячие клавиши

Вне текстовых полей:

| Сочетание | Действие |
| :--- | :--- |
| `Ctrl + V` | Загрузить изображение из буфера |
| `Ctrl + Z` | Отменить изменение |
| `Ctrl + Y` | Повторить изменение |
| `Ctrl + X` | Сбросить к исходному фото |
| `Ctrl + M` | Открыть подтверждение удаления |
| `Ctrl + 1 / 2 / 3` | Раскрыть «Цвет» / «Шум» / «Контуры» |

Колёсико мыши меняет масштаб, перетаскивание перемещает увеличенное фото.
Двойной щелчок переключает масштаб между 100% и вписыванием в окно.

## Устройство проекта

**Next.js App Router · React · TypeScript · Tailwind CSS · shadcn/ui · Radix UI · anime.js**

FSD без `src`. Папка `app` содержит маршруты Next.js, общий layout и стили.

```text
app/                            маршруты редактора и визуального стенда
widgets/
  editor/                       компоновка рабочего редактора
  ui-kit/                       компоненты стенда и примеры
features/
  image-upload/                 импорт файлов, ссылок и буфера обмена
  image-filters/                каталог фильтров, параметры и гистограмма
  image-history/                история и просмотр оригинала
  image-export/                 подготовка файла и скачивание
  image-geometry/               размер и обрезка
  image-viewport/               масштаб, перемещение и пипетка
entities/image/                 модель изображения, история и метаданные
shared/
  ui/                           общие компоненты, тема и анимации
  lib/image-processing/         алгоритмы, Web Worker и WebGL2
scripts/fsd-rules.mjs            правила импортов между слоями
```

Слои импортируют нижележащие слои. Слайсы одного слоя независимы;
внешние импорты идут через публичный `index.ts`. Границы проверяет ESLint.

### Обработка изображений

1. Загруженное изображение преобразуется в WebP.
2. Фильтры, гистограмма, геометрические операции и экспорт выполняются
   в Web Worker через OffscreenCanvas.
3. Поддерживаемые фильтры используют WebGL2 для достаточно больших изображений.
   Если GPU недоступен, обработка остаётся на CPU внутри воркера.
4. История хранит WebP и маленькие миниатюры. Полноразмерное изображение
   декодируется для активного шага и, при необходимости, оригинала.

Тяжёлая обработка не выполняется синхронно в основном потоке. Для медианного
фильтра используется скользящая гистограмма. Размер окна 5 × 5 означает
25 пикселей.

<details>
<summary><strong>Форматы и ограничения</strong></summary>

- Рабочий формат — **WebP**. Внутреннее качество 100% не означает сжатие без потерь.
- При скачивании по умолчанию выбран WebP с качеством 95%.
  Для WebP/JPEG качество задаётся от 1 до 100.
- WebP и PNG сохраняют прозрачность. В JPEG прозрачные области становятся белыми.
- Исходные EXIF-метаданные отображаются в карточке данных, но не переносятся
  в экспортированный файл.
- Изменение размера: от 1 до 8192 px по стороне, максимум 16 млн пикселей.
- Ссылка должна вести на изображение и разрешать загрузку из другого
  источника через CORS.
- Нужен браузер с Web Workers и OffscreenCanvas. WebGL2 необязателен.
- Фото и история остаются в памяти текущей страницы и сбрасываются
  после перезагрузки. Настройки интерфейса сохраняются отдельно.

</details>
